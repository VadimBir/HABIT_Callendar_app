# OpenFront offline APK

`OpenFront-offline-slim-debug.apk` — Capacitor-wrapped OpenFrontIO, single-player
offline, v2-signed debug build (~46 MB). Bundles 6 maps (onion, bosphorusstraits,
pangaea, danishstraits, caucasus, world) to stay under chat/GitHub size limits;
the full map set is available by rebuilding from `openfront/` source.

Sideload on Android: download → Files → Downloads → tap APK → allow unknown
sources → Install → Open → Single Player.
